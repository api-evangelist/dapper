# Dapper

Dapper was an advertising-technology and web-data company founded in 2006 by Jonathan Aizen and Eran Shir, seed-funded by Accel.

It ran two surfaces:

- **Dapper Ads** — intent-driven dynamic ads that pulled live product and inventory data from an advertiser's own site into targeted creative, with no IT integration required.
- **open.dapper.net ("Dapp Factory" / Dapper: The Data Mapper)** — a hosted tool that turned any web page into structured feeds, web services and widgets (XML, RSS, JSON, YAML, CSV, iCalendar, Google Gadgets, Netvibes modules, image loops), letting anyone "create an API for any site."

Dapper was acquired by Yahoo! in 2010 and both surfaces were shut down. `dapper.net` now resolves to Yahoo nameservers with no host record, and `open.dapper.net` no longer resolves at all.

**Status:** defunct — no live API, developer portal, or documentation to enrich.
